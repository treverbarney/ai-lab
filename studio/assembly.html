YOUR NATIVE DESIGN

Fusion, connected.

Keep Fusion open with the Fusion360MCP add-in running. This panel reads native parameters and root-component bodies. The Dino enclosure remains its own editable design.

First-time connection setup

In Dino desktop → Engineering → Dino Fusion, install the wrapper. Register the upstream engineering/fusion360-mcp/Fusion360MCP folder through Fusion’s Scripts and Add-Ins dialog, then Run the add-in. The default bridge port is 9876. Return here and connect.

To bring a Dino assembly into Fusion, download its STEP file and open/import it in Fusion. Keep the source JSON to regenerate dimensions and joints in Dino; STEP import does not recreate native parametric features or mechanical joints.
